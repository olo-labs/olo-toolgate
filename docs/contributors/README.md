# Contributor Guide

## First 5 Minutes

1. Run `make dev`.
2. Open the Admin UI.
3. Run `make check`.
4. Read `docs/architecture/component-map.md`.
5. Pick a `good first issue`.

## Contribution Paths

### Backend

Gateway, Control Plane, Marketplace API/Worker.

### Frontend

Admin UX and Drupal Marketplace.

### Endpoint

Windows/Linux/macOS client, runtimes and enforcement.

### Security

Policies, credentials, signing, sandboxing, supply chain.

### Documentation

Quickstarts, examples, diagrams and tutorials.

### Integrations

Vault providers, resource extractors, package runtimes and examples.
