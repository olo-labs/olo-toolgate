## Make your first PR

1. Comment on an issue to check availability and ask any questions.
2. Fork the repository and create a branch for your change.
3. Follow the issue's scope; these tasks do not require runtime or permission changes.
4. Preview the Markdown, check added links, and perform the issue's validation steps.
5. Open a PR describing the change and your checks. Include `Closes #NUMBER`.

Draft PRs are welcome if you need help verifying an example or platform-specific
UI text. Avoid real credentials and personal data in examples or screenshots.
Read the [contribution guide](../../CONTRIBUTING.md) for repository conventions,
required checks, and code contributions.
