# Good First Contribution Ideas

Good first issues should be small, independently testable and require understanding only one component.

Examples:

- add a resource extractor fixture
- improve an error message
- add a built-in tool unit test
- add a JSON/YAML example
- improve a Quickstart screen
- add Marketplace package validation test
- add metrics documentation
- add a client runtime health test
- add one safe example package
- improve `make dev` diagnostics
- add missing docs links
- add accessibility improvements

Maintainers should keep a healthy supply of issues labeled:

```text
good first issue
help wanted
docs
testing
frontend
rust
java
security
marketplace
client
```
