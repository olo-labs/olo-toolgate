# Client Fleet Management

The current Clients table combines registered devices and pending requests, with device names, registered users and detail tooltips. Enable/Disable and Approve/Deapprove are independent; approval may be timed or explicitly unlimited. Quickstart separately registers the fixed executor, HotFolder and REST forwarding. Heartbeats cannot invalidate the separate approval revision. Redeployment preserves existing identities and seeds only missing server devices.

See [Device registry and tool-call controls](device-registry.md).

## Purpose

Enrollment, inventory, desired state, rollout, failures, health, offline, rollback and package version drift.
