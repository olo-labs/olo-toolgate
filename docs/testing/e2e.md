# End-to-End Tests

## Purpose

Fresh Quickstart, stateless production, client enrollment, HotFolder, Marketplace import/deploy, custom tool publish/import loop.

The [registry flow](../control-plane/device-registry.md) must cover pending requests
in the combined table, visible names/users, accessible details and timed/unlimited
forms. Exercise real CSR/mTLS client disable/deapprove/reapprove and separate server
devices, HotFolder device filters and REST forwarding suspension. Restart and backup/
restore must retain owners, approvals and enablement.
