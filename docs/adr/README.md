# Architecture Decision Records

Create an ADR when changing:

- component responsibility.
- major language/runtime.
- policy engine.
- cryptographic format.
- package format.
- signing/trust model.
- persistent-store choice.
- endpoint enforcement approach.
- public API compatibility.
