# Support

## Questions and Ideas

Use GitHub Discussions for:

- architecture questions
- integration ideas
- use cases
- contributor questions
- Marketplace/package ideas

## Bugs

Open a Bug Report issue.

Include:

```text
ToolGate version
component
OS/environment
steps to reproduce
expected behavior
actual behavior
safe logs / trace ID
```

Never attach credentials.

## Feature Requests

Open a Feature Request or Discussion.

Explain the workflow you are trying to accomplish before proposing an implementation.

## Security

Do not open a public issue.

Read [`SECURITY.md`](SECURITY.md).
